## 1. What is Zen?

### Philosophy

Zen was designed to make scripting feel natural. Instead of boilerplate, you write **intentions**:

```zen
print "Hello, World!"
let links = ["a", "b", "c"]
for link in links { print link }
```

**Core principles:**
- **Python-like readability** — clean syntax, optional semicolons, dynamic typing
- **JavaScript-like expressiveness** — template literals, arrow functions, destructuring, `===`, `?.`, `??`
- **Batteries-included stdlib** — 35+ built-in modules (HTTP, crypto, regex, filesystem, email, networking, and more)
- **Zero install friction** — all modules are baked into the runtime, no `pip install` or `npm` needed

### What can you do with Zen?

- Automate tasks and glue together system commands
- Scrape data from websites (SPAs, JS-rendered pages)
- Make HTTP requests, parse APIs, consume JSON
- Work with files, directories, CSVs, and structured data
- Hash passwords, encrypt data, generate UUIDs
- Send emails (SMTP), read mail (IMAP/POP3), connect to FTP/SSH servers, resolve DNS
- Write CLI tools, helpers, and quick prototypes
- Run browser automation scripts (Chromium via CDP)

### Zen vs Python vs JavaScript

| Feature | Zen | Python | JavaScript |
|---------|-----|--------|------------|
| Typing | Dynamic | Dynamic | Dynamic |
| Syntax style | Python-like | Indentation | Braces |
| Semicolons | Optional | None | Required |
| `print` | `print "hi"` | `print("hi")` | `console.log("hi")` |
| Null | `null` | `None` | `null` |
| Boolean | `true`/`false` | `True`/`False` | `true`/`false` |
| String interp | `"${x}"` / `` `${x}` `` | `f"{x}"` | `` `${x}` `` |
| Lambdas | `lambda x: x * 2` | `lambda x: x * 2` | `x => x * 2` |
| Arrow funcs | `(x) => x * 2` | N/A | `(x) => x * 2` |
| Classes | `class Foo {}` | `class Foo:` | `class Foo {}` |
| Nullish coalescing | `x ?? default` | `x or default` | `x ?? default` |
| Safe navigation | `x?.y` | N/A | `x?.y` |
| Ranges | `1 -> 10` | `range(1, 11)` | N/A |
| Modules | Built-in globals | `import math` | `require('...')` |

## 2. Installation & Hello World

### Install from Source

```bash
git clone https://github.com/NoxelEcnord/zen.git
cd zen
cargo build --release
# binary at target/release/zen — add to PATH
```

### Verify

```bash
zen --version
```

### Hello World

Create `hello.z`:

```zen
print "Hello, World!"
```

Run it:

```bash
zen run hello.z
```

Output:

```
Hello, World!
```

### Inline Evaluation

Run code without creating a file:

```bash
zen -e 'print 2 + 2'
```

Output: `4`

### The Interactive Shell

```bash
zen shell
```

```
zen> print "hello"
hello
zen> 2 ** 10
1024
zen> "zen".upper()
ZEN
```

Every expression you type is evaluated and printed. Statements (assignments, loops) don't produce output.

### Shell Commands

| Command | Description |
|---------|-------------|
| `.exit` / `.quit` | Exit the shell |
| `.help` | Show help |
| `.help modules` | List all modules |
| `.help <module>` | Module-specific help |
| `.help types` | List all data types |
| `.help functions` | List built-in functions |
| `.help operators` | List all operators |
| `.clear` | Clear screen |
| `.vars` | Show your variables |
| `.history` | Command history |
| `.run file.z` | Run a script |
| `.shot file.png` | Take a screenshot |

**Common mistake:** Forgetting that the shell auto-prints expressions but not statements.

```zen
zen> let x = 5        # no output (assignment is a statement)
zen> x                 # prints 5 (expression)
5
```

**Pro tip:** Use `Tab` for auto-completion and arrow keys for history.

## 3. Variables & Types

### Declaring Variables

```zen
let name = "Zen"         # mutable variable
const PI = 3.14159       # immutable constant
count = 0                # auto-declares if new (same as let)
```

**`let` vs `const`:**
- `let` — variable can be reassigned
- `const` — attempting reassignment throws an error

```zen
let x = 10
x = 20          # OK
const y = 10
y = 20          # Error: cannot reassign constant
```

### Compound Assignment & Increment/Decrement

```zen
let x = 10
x += 5          # x = 15
x -= 3          # x = 12
x *= 2          # x = 24
x /= 4          # x = 6
x %= 5          # x = 1
x++             # x = 2
x--             # x = 1
```

Compound assignment also works on member access and index access:

```zen
let obj = {count: 0}
obj.count += 1            # {count: 1}

let items = [10, 20, 30]
items[0] += 100           # [110, 20, 30]
```

### Data Types

| Type | Examples | `typeof` result | Truthy? |
|------|----------|----------------|---------|
| Null | `null` | `"null"` | No |
| Bool | `true`, `false` | `"bool"` | `false`/`true` |
| Number | `42`, `3.14`, `-7` | `"int"` | Non-zero |
| String | `"hello"`, `'world'` | `"string"` | Non-empty |
| List | `[1, 2, 3]` | `"list"` | Non-empty |
| Dict | `{"a": 1}` | `"dict"` | Non-empty |
| Function | `function() {}` | `"function"` | Always |
| Object | `new Foo()` | `"object"` | Always |

**Note:** All numbers are 64-bit floats internally, but Zen displays whole numbers without decimals.

```zen
type(42)         # "int"
type(3.14)       # "float"
type("hello")    # "string"
type(true)       # "bool"
type(null)       # "null"
type([1, 2])     # "list"
type({a: 1})     # "dict"
```

### Type Conversion

```zen
str(42)          # "42"
str(3.14)        # "3.14"
str(true)        # "true"
str(null)        # "null"
str([1, 2])      # "[1, 2]"

int("42")        # 42
int(3.9)         # 3  (truncated toward zero)
int("3.14")      # 3
int(true)        # 1
int(false)       # 0

float(42)        # 42.0
float("3.14")    # 3.14

bool(0)          # false
bool(1)          # true
bool("")         # false
bool("hello")    # true
bool([])         # false
bool([1])        # true
bool(null)       # false

list("abc")      # ["a", "b", "c"]
list({a: 1})     # [["a", 1]]

dict([["a", 1], ["b", 2]])    # {"a": 1, "b": 2}
```

### Truthiness

**Falsy values:** `false`, `null`, `0`, `0.0`, `""` (empty string), `[]` (empty list), `{}` (empty dict).

**Everything else is truthy** — including non-empty strings, negative numbers, and all objects.

```zen
if "" { print "won't run" }
if "hello" { print "runs!" }

if 0 { print "nope" }
if -1 { print "yes, negative is truthy" }
```

### Scope Rules

Variables declared with `let` are **block-scoped**:

```zen
let x = 10
if true {
    let x = 20       # different x, block-scoped
    print x           # 20
}
print x               # 10
```

Functions create their own scope. Closures capture outer variables:

```zen
let multiplier = 10
function times(n) {
    return n * multiplier   # captures multiplier
}
print times(5)              # 50
```

### Tuple Unpacking

```zen
a, b = 1, 2               # a=1, b=2
x, y = [10, 20]            # x=10, y=20

# Use _ as throwaway
name, _ = ["Alice", "alice@example.com"]
```

**Common mistake:** Unpacking with `let` doesn't work — use bare assignment:

```zen
# let [x, y] = [1, 2]    # Error
x, y = [1, 2]              # Correct
```

### The `typeof` Operator

```zen
typeof 42          # "int"
typeof "hello"     # "string"
typeof null        # "null"
typeof [1]         # "list"
typeof {}          # "dict"
```

`type(x)` is an alias for `typeof x`.

### Special Variables

| Variable | Description |
|----------|-------------|
| `_` | Last expression result (also a throwaway in unpacking) |
| `_url` | Current page URL (browser mode) |
| `_time` | Current time (HH:MM:SS) |
| `_date` | Current date (YYYY-MM-DD) |
| `_dir` | Current working directory |
| `_version` | Zen version string |
| `_timeout` | Default timeout (read/write) |

## 4. Strings

### Quoting Styles

```zen
# Single-quoted — literal, no interpolation
'hello world'
'it\'s a string'

# Double-quoted — supports ${} interpolation
"Hello, World!"
"2 + 2 = ${2 + 2}"

# Triple-quoted — preserves newlines and indentation
"""
This is a
multi-line string.
"""
```

**Key difference:** Single quotes have no interpolation. Double quotes support `${expression}`. Both support escape sequences.

### String Interpolation

**Double-quoted strings** support `${}` for embedding any expression:

```zen
let name = "World"
let x = 10

print "Hello, ${name}!"              # Hello, World!
print "${x} + ${x} = ${x + x}"      # 10 + 10 = 20
print "Type: ${typeof name}"         # Type: string

let items = [1, 2, 3]
print "Count: ${items.len}"          # Count: 3
```

### Template Literals (Backtick Strings)

Backtick strings work like JavaScript — they support full `${}` expressions:

```zen
let name = "Zen"
let version = 1

print `Hello ${name} v${version}!`         # Hello Zen v1!
print `${100 * 3.14}`                       # 314

let items = ["a", "b", "c"]
print `Items: ${items.join(", ")}`          # Items: a, b, c
```

**When to use which?**
- `"string with ${x}"` — standard, works everywhere
- `` `template with ${x}` `` — same thing, JS-familiar
- `'literal string'` — when you need no interpolation

### Escape Sequences

| Escape | Meaning |
|--------|---------|
| `\n` | Newline |
| `\t` | Tab |
| `\r` | Carriage return |
| `\\` | Literal backslash |
| `\"` | Literal double quote |
| `\'` | Literal single quote |
| `\$` | Literal dollar sign (double-quoted) |
| `\0` | Null character |

### String Methods

```zen
"hello".upper()                        # "HELLO"
"HELLO".lower()                        # "hello"
"Hello World".title()                  # "Hello World"
"hElLo".capitalize()                   # "Hello"

"  zen  ".strip()                      # "zen"
"  zen  ".lstrip()                     # "zen  "
"  zen  ".rstrip()                     # "  zen"

"a,b,c".split(",")                     # ["a", "b", "c"]
"hello world".split()                  # ["hello", "world"]
"a\nb\nc".splitlines()                # ["a", "b", "c"]

"-".join(["a", "b", "c"])              # "a-b-c"

"hello world".replace("world", "zen")  # "hello zen"
"hello world".find("world")            # 6  (-1 if not found)
"hello".count("l")                     # 2
"hello".startswith("he")               # true
"hello".endswith("lo")                 # true
"hello".contains("ell")                # true

"hello".len                            # 5
"hello".count                          # 5  (alias for len)

"hello {0}".format("world")            # "hello world"

"abc".repeat(3)                        # "abcabcabc"
"42".isdigit()                         # true
"abc".isalpha()                        # true
"hello".ljust(10, "-")                 # "hello-----"
"hello".rjust(10, "-")                 # "-----hello"
"hello".center(10, "-")                # "--hello---"
"42".zfill(5)                          # "00042"
```

### The `string` Module

```zen
string.upper("hello")                  # "HELLO"
string.lower("HELLO")                  # "hello"
string.strip("  zen  ")               # "zen"
string.split("a,b,c", ",")            # ["a", "b", "c"]
string.join("-", ["a", "b", "c"])      # "a-b-c"
string.replace("hello", "l", "L")     # "heLLo"
string.count("hello", "l")            # 2
string.isdigit("42")                   # true

# Constants
string.digits                          # "0123456789"
string.ascii_letters                   # "abcdefghijklmnopqrstuvwxyzABC..."
string.punctuation                     # special characters
string.ascii_lowercase                 # "abcdefghijklmnopqrstuvwxyz"
string.ascii_uppercase                 # "ABCDEFGHIJKLMNOPQRSTUVWXYZ"
```

**Pro tip:** Strings are immutable — methods return new strings.

```zen
let s = "hello"
s.upper()          # returns "HELLO" — s is still "hello"
```

## 5. Numbers & Math

### Basics

All numbers are 64-bit floats internally. Zen displays whole numbers without decimals:

```zen
42          # integer display
3.14        # float display
-7          # negative
```

### Arithmetic

```zen
2 + 3       # 5
10 - 4      # 6
3 * 7       # 21
10 / 3      # 3.3333...
10 / 2      # 5.0
10 % 3      # 1  (modulo)
2 ** 10     # 1024  (exponentiation)
-5          # negation
```

### The `math` Module

```zen
# Constants
math.pi                 # 3.141592653589793
math.e                  # 2.718281828459045
math.inf                # infinity
math.nan                # NaN

# Roots & Rounding
math.sqrt(25)           # 5.0
math.floor(3.7)         # 3
math.ceil(3.2)          # 4
math.trunc(3.9)         # 3
math.round(3.5)         # 4
math.abs(-42)           # 42
math.pow(2, 10)         # 1024

# Trigonometry
math.sin(math.pi / 2)   # 1.0
math.cos(0)              # 1.0
math.tan(math.pi / 4)   # ~1.0

# Logarithms
math.log(100)            # ~4.605 (natural log)
math.log2(1024)          # 10.0
math.log10(1000)         # 3.0

# Combinatorics
math.factorial(5)        # 120
math.comb(10, 3)         # 120  (combinations)
math.perm(10, 3)         # 720  (permutations)
math.gcd(12, 8)          # 4
math.lcm(4, 6)           # 12

# Checks
math.isnan(math.nan)     # true
math.isinf(math.inf)     # true
math.isfinite(42)        # true
```

### Number Methods

```zen
let n = 42
n.str()                  # "42"
n.float()                # 42.0

(3.14).round()           # 3
(3.14159).round(2)       # 3.14
(3.14).trunc()           # 3
(42.0).int()             # 42

3.times(function(i) { print i })   # 0, 1, 2
```

### Built-in Numeric Functions

```zen
abs(-5)                  # 5
min(3, 1, 2)            # 1
max(3, 1, 2)            # 3
round(3.7)              # 4
hex(255)                 # "0xff"
```

### Random Numbers

```zen
random.random()            # 0.0 to 1.0
random.randint(1, 100)     # integer 1-100
random.choice([1, 2, 3])   # random element
random.shuffle([1, 2, 3])  # shuffle in place
random.uniform(1.0, 10.0)  # float in range
random.seed(42)             # reproducible results
```

### Precision: The `decimal` Module

```zen
let a = decimal.Decimal("0.1")
let b = decimal.Decimal("0.2")
let c = decimal.Decimal("0.3")
print a + b == c         # true (unlike raw floats!)

decimal.getcontext()     # {prec: 28, rounding: "ROUND_HALF_EVEN"}
decimal.setcontext({prec: 10})
```

### Statistics

```zen
statistics.mean([1, 2, 3, 4, 5])       # 3
statistics.median([1, 2, 3, 4, 5])     # 3
statistics.mode([1, 1, 2, 3])          # 1
statistics.stdev([1, 2, 3, 4, 5])      # ~1.58
statistics.variance([1, 2, 3, 4, 5])   # ~2.5
statistics.sum([1, 2, 3])              # 6
```

## 6. Control Flow

### If / Elif / Else

```zen
let score = 85

if score >= 90 {
    print "A"
} elif score >= 80 {
    print "B"
} elif score >= 70 {
    print "C"
} else {
    print "D"
}
# Output: B
```

`else if` is synonymous with `elif`.

### Ternary Conditional

```zen
# JavaScript style
let grade = score >= 50 ? "pass" : "fail"

# Python style (also works)
let grade = "pass" if score >= 50 else "fail"

# Nested ternary
let label = x > 100 ? "high" : x > 50 ? "medium" : "low"
```

### While Loops

```zen
let x = 5
while x > 0 {
    print x
    x--
}
# 5, 4, 3, 2, 1
```

### For-In Loops

```zen
# Iterate over a list
for item in [1, 2, 3] { print item }

# Iterate over a range
for i in 1 -> 5 { print i }
# 1, 2, 3, 4, 5

# Iterate over a string (each character)
for ch in "hello" { print ch }

# Iterate over a dict's keys
let user = {name: "Alice", age: 30}
for key in user {
    print key + " = " + user[key]
}
```

### Break & Continue

```zen
let i = 0
while true {
    i++
    if i == 2 { continue }    # skip 2
    print i
    if i >= 5 { break }
}
# 1, 3, 4, 5
```

### Switch / Case

```zen
switch command {
    case "start" { start_server() }
    case "stop"  { stop_server() }
    case "restart" { restart_server() }
    default { print "Unknown command" }
}
```

The first matching case wins. `default` is optional.

### Ranges (`->`, `..`, `to`)

```zen
1 -> 5           # [1, 2, 3, 4, 5]   (inclusive)
1 .. 10          # [1, 2, ..., 10]   (alias)
5 -> 1           # [5, 4, 3, 2, 1]   (auto-descending)

# With step
1 -> 10 by 2     # [1, 3, 5, 7, 9]
1 .. 10 @ 3      # [1, 4, 7, 10]     (@ is alias for by)
```

### Spread (`...`)

```zen
let a = [1, 2, 3]
let b = [...a, 4, 5]          # [1, 2, 3, 4, 5]

let d1 = {"x": 1}
let d2 = {...d1, "y": 2}      # {"x": 1, "y": 2}
```

### Safe Navigation (`?.`)

Access properties that might be `null` without crashing:

```zen
let name = user?.name          # null if user is null
let result = obj?.method()     # null if obj is null
```

### Nullish Coalescing (`??`)

```zen
let name = input ?? "default"   # uses "default" only if input is null
```

### Identity & Membership

```zen
# Identity
null is null       # true
[] is []           # false (different objects)
1 is not "1"       # true

# Membership
"world" in "hello world"     # true (substring)
42 in [1, 2, 42]              # true (list contains)
"x" in {"x": 1}               # true (dict key)
"z" not in {"x": 1}           # true
```

### Logical Operators

```zen
true and false     # false
true or false      # true
not true           # false

# Also available as JS-style aliases
true && false      # false
true || false      # true
```

Short-circuit evaluation applies:

```zen
true or print("never runs")     # true
false and print("never runs")   # false
```

### Bitwise Operators

```zen
5 & 3        # 1  (AND)
5 | 3        # 7  (OR)
5 ^ 3        # 6  (XOR)
~5           # -6 (NOT)
5 << 1       # 10 (left shift)
10 >> 1      # 5  (right shift)
```

### Chained Comparisons

```zen
1 < 5 < 10       # true: (1 < 5) and (5 < 10)
0 <= x < 100     # true if x is between 0 and 99
a == b == c      # true if all equal
```

### Strict Equality

```zen
# == is loose (value equality)
1 == "1"         # true (type coercion)

# === is strict (type + value)
1 === "1"        # false
1 === 1          # true
```

### The `with` Statement

Temporarily extend scope:

```zen
with load_config() as cfg {
    print cfg["host"]
    print cfg["port"]
}
# cfg is not accessible here
```

## 7. Functions

### Named Functions

```zen
function greet(name) {
    return "Hello, " + name + "!"
}

print greet("Zen")   # Hello, Zen!
```

`def`, `func`, and `function` are all equivalent:

```zen
def add(a, b) {
    return a + b
}

func multiply(a, b) {
    return a * b
}
```

### Default Parameters

```zen
function greet(name = "World") {
    return "Hello, " + name + "!"
}

print greet()       # Hello, World!
print greet("Zen")  # Hello, Zen!
```

### Returning Values

Functions without an explicit `return` return `null`. `return` with no value also returns `null`.

```zen
function do_nothing() { }     # returns null
function get_value() { return 42 }  # returns 42
```

### Closures

Functions capture their surrounding scope:

```zen
function make_counter(start) {
    let count = start
    return function() {
        count++
        return count
    }
}

let counter = make_counter(0)
print counter()   # 1
print counter()   # 2
print counter()   # 3
```

### Anonymous Functions

```zen
let double = function(n) {
    return n * 2
}
print double(21)   # 42
```

### Lambda Expressions

Compact single-expression functions:

```zen
# Colon syntax (body is the expression after colon)
let double = lambda x: x * 2
print double(5)     # 10

# Multi-param
let add = lambda x, y: x + y
print add(3, 4)     # 7

# Block syntax
let greet = lambda(name) {
    return "Hello, " + name
}
print greet("Zen")  # Hello, Zen
```

### Arrow Functions

JavaScript-style arrows:

```zen
# Single expression
let double = (x) => x * 2
print double(5)     # 10

# Multi-param
let add = (x, y) => x + y
print add(3, 4)     # 7

# Block body
let greet = (name) => {
    return "Hello, " + name
}
```

### Higher-Order Functions

Functions that take or return other functions:

```zen
# map — transform each element
let doubled = [1, 2, 3].map(lambda x: x * 2)
# [2, 4, 6]

# filter — keep elements matching predicate
let evens = [1, 2, 3, 4, 5].filter(lambda x: x % 2 == 0)
# [2, 4]

# reduce — fold to single value
let sum = [1, 2, 3, 4].reduce(lambda acc, x: acc + x, 0)
# 10

# enumerate — pairs index with value
let pairs = ["a", "b", "c"].enumerate()
# [[0, "a"], [1, "b"], [2, "c"]]

# Functional builtins (also available globally)
map(lambda x: x * 2, [1, 2, 3])          # [2, 4, 6]
filter(lambda x: x > 1, [1, 2, 3])       # [2, 3]
reduce(lambda a, b: a + b, [1, 2, 3])    # 6
zip([1, 2], ["a", "b"])                   # [[1, "a"], [2, "b"]]
```

### The `times` Method on Numbers

```zen
5.times(function(i) {
    print i
})
# 0, 1, 2, 3, 4
```

## 8. Lists

### Creating Lists

```zen
let nums = [1, 2, 3, 4, 5]
let mixed = [1, "two", true, 3.14]
let empty = []
let trailing = [1, 2, 3,]         # trailing comma OK
```

### Indexing

```zen
let items = ["a", "b", "c", "d"]

items[0]         # "a"  (first)
items[-1]        # "d"  (last)
items[-2]        # "c"  (second to last)
```

### List Methods

```zen
let items = [1, 2, 3]

items.append(4)         # [1, 2, 3, 4]   (mutates)
items.push(5)           # alias for append
```

Methods are functions assigned in the class body. The first parameter `self` refers to the current instance:

### Inheritance

```zen

class Dog extends Animal {
```

## 15. Regex

### The `re` Module

```zen

m.groups()                             # ["user", "example"]

# Find all matches
re.findall("\\d+", "a1 b22 c3")       # ["1", "22", "3"]

# Replace
re.sub("\\d+", "X", "abc 123 def")    # "abc X def"

# Split
re.split("\\s+", "a b   c")           # ["a", "b", "c"]
```

```zen
function backup_files(src_dir, backup_dir) {
    if !fs.exists(src_dir) {
        print color.red("Source directory not found: ${src_dir}")
        return
    }

    fs.mkdirs(backup_dir)

    let timestamp = datetime.format(datetime.now(), "%Y%m%d_%H%M%S")
    let backup_name = fs.join(backup_dir, "backup_${timestamp}")
    fs.mkdirs(backup_name)

    let files = fs.glob(fs.join(src_dir, "*"))
    let count = 0

    for file in files {
        if fs.is_file(file) {
            let name = fs.basename(file)
            fs.copy(file, fs.join(backup_name, name))
            count++
            print "  Copied: ${name}"
        }
    }

    print color.green("Backed up ${count} files to ${backup_name}")
}

backup_files("./data", "./backups")
```

```zen
function generate_password(length = 16, use_special = true) {
    let lowercase = "abcdefghijklmnopqrstuvwxyz"
    let uppercase = "ABCDEFGHIJKLMNOPQRSTUVWXYZ"
    let digits = "0123456789"
    let special = "!@#$%^&*()-_=+[]{}|;:,.<>?"

    let charset = lowercase + uppercase + digits
    if use_special {
        charset = charset + special
    }

    let password = ""
    for i in 1 -> length {
        let idx = random.randint(0, charset.len - 1)
        password = password + charset[idx]
    }

    return password
}

# Generate 5 passwords
for i in 1 -> 5 {
    let pwd = generate_password(20)
    let strength = if pwd.len >= 16 { color.green("strong") } else { color.yellow("medium") }
    print "${pwd}  (${strength})"
}
```
