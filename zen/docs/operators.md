# Operators in Zen

- `+` — addition / string concat
- `-` — subtraction
- `*` — multiplication
- `/` — division
- `%` — modulo
- `**` — power
- `==`, `!=`, `>` `<` `>=` `<=` — comparison
- `and`, `or`, `not` — logical
- `.` — property/method access
- `[]` — index / key access
- `=`, `+=`, `-=`, etc. — assignment
