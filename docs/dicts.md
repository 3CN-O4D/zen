# Dictionaries

```zen
let d = {name: "Ada", age: 36}
d.keys()                     // ["name", "age"]
d.values()                   // ["Ada", 36]
d.len()                      // 2
d.contains("name")           // true
d.get("name", "default")     // value or default
{...d, city: "London"}        // spread
```
