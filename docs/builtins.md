# Built-in Functions

Always available without import:

- `print(...)` — output
- `input()` — read line
- `len(x)` — length
- `str(x)` `int(x)` `float(x)` `bool(x)` `list(x)` — conversion
- `type(x)` `typeof x` — type name
- `abs(x)` `min(...)` `max(...)`
- `round(x)` `trunc(x)` `hex(x)`
- `range(end)` `range(start, end)`
- `exit(code)`
- `sleep(sec)` `wait(sec)`
