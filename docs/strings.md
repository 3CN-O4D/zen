# Strings

```zen
"hello".len()              // 5 (also .length)
"hello".upper()             // "HELLO"
"hello".lower()             // "hello"
"hello".trim()              // "hello" (also .strip())
"hello".split(",")          // ["hello"]
"hello".contains("ell")     // true
"hello".replace("l", "x")   // "hexlo"
"hello".slice(1, 3)         // "el"
"hello".repeat(2)           // "hellohello"
"abc".toList()              // ["a", "b", "c"]
```
