# Keywords

- `let` `const` `global` — variables
- `function` `func` `fn` `def` — define function
- `lambda` — anonymous function
- `class` `new` `extends` `inherit` — OOP
- `this` `self` — instance reference
- `if` `elif` `else` — conditional
- `while` `for` `in` — loops
- `break` `continue` — loop control
- `return` — return value
- `throw` `raise` — raise error
- `try` `catch` `except` `finally` — error handling
- `import` `from` `as` `load` `include` — imports
- `switch` `case` `default` — pattern match
- `null` `true` `false` — literals
- `typeof` `and` `or` `not` — operators
