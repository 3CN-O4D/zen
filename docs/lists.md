# Lists

```zen
let xs = [1, 2, 3]
xs.push(4)            // append
xs.pop()              // remove last
xs.shift()            // remove first
xs.unshift(0)         // insert front
xs.contains(2)        // true
xs.join(",")          // "1,2,3"
xs.len()              // 3
[0, ...xs, 4]         // spread: [0, 1, 2, 3, 4]
```
