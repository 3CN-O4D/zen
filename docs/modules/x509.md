# x509 — certificate inspection

The `x509` module parses PEM certificates offline: subject/issuer names,
serial, validity window, SAN list, CA flag, signature algorithm, and public
key facts. It is available globally as `x509`.

Structure only — no chain building, no signature verification, no network.
Live handshakes need a TLS connector (a later milestone); this answers "what
does this certificate say?" for PEM you already hold.

```zen
# Offline inspection of a captured certificate
var cert = x509.parse_pem(fs.read("site.pem"))
print(cert["subject"])    # CN=audit-lab.example, O=Zen Audit, C=US
print(cert["not_after"])  # 2036-10-13T02:32:04Z
print(cert["san"])        # [audit-lab.example, www.audit-lab.example]
```

## Functions

| Function | Description |
|----------|-------------|
| `parse_pem(pem)` | Parses one PEM certificate into a dict; throws on malformed input. |

## The certificate dictionary

| Field | Type | Description |
|-------|------|-------------|
| `subject` / `issuer` | `string` | `CN=..., O=..., C=...` style names. |
| `serial_hex` | `string` | Uppercase hex serial. |
| `version` | `int` | X.509 version (usually 3). |
| `not_before` / `not_after` | `string` | ISO-8601 UTC timestamps. |
| `not_before_epoch` / `not_after_epoch` | `int` | Unix timestamps (for expiry math). |
| `san` | `list` | DNS subject-alternative names. |
| `is_ca` | `bool` | Basic-constraints CA flag. |
| `sig_algo` | `string` | e.g. `sha256WithRSAEncryption`. |
| `key_algo` / `key_bits` | `string` / `int` | `rsa`/`ec`/`dsa`/`unknown` and key size. |
