# Statistics Module (`statistics`)

Statistical calculations.

```zen
statistics.mean([1, 2, 3])     // 2.0
statistics.median([1, 2, 3])   // 2.0
statistics.mode([1, 2, 2, 3])  // 2
statistics.stdev([1, 2, 3])    // 1.0
statistics.variance([1, 2, 3]) // 1.0
statistics.sum([1, 2, 3])      // 6
statistics.min([1, 2, 3])      // 1
statistics.max([1, 2, 3])      // 3
```
